# eBook delivery folder

The private Vercel Blob object is named `hairfallguide.pdf`. The buyer download is named `hair-fall-control-guide.pdf`.

**Important:** Files placed under `public/` are publicly accessible to anyone who knows or discovers the URL. Do not put the paid eBook here on a live storefront if it must remain private until payment is verified. Keep the PDF in private storage and deliver it from a backend only after the payment provider confirms the transaction. This folder is reserved for local setup or a deliberately public file.
